# INTAN SHOP

INTAN SHOP adalah website e-commerce premium bertema luxury jewelry dan fashion collection. Website ini dibangun dengan HTML5, CSS3, dan Vanilla JavaScript ES6 tanpa framework.

## Deskripsi
- Menyediakan pengalaman belanja premium untuk produk seperti diamond, gold jewelry, necklace, bracelet, rings, luxury bags, watches, dan gift collection.
- Mendukung alur lengkap: splash screen, login, home, shop, product detail, cart, checkout, payment, success, invoice, dan admin dashboard.
- Semua fungsionalitas disimpan melalui LocalStorage untuk simulasi pengalaman e-commerce nyata.

## Cara Install
1. Clone repository atau unduh folder project.
2. Buka folder project pada VS Code.
3. Jalankan server lokal seperti `python -m http.server 8000`.
4. Buka `http://localhost:8000` pada browser.

## Struktur Folder
- `index.html` - landing page utama
- `login.html` - halaman login premium
- `product.html` - katalog produk dengan search dan filter
- `product-detail.html` - halaman detail produk
- `cart.html` - halaman keranjang
- `checkout.html` - formulir pengiriman
- `payment.html` - pilihan metode pembayaran
- `success.html` - halaman pembayaran sukses
- `invoice.html` - invoice otomatis
- `about.html`, `contact.html`, `business-overview.html`, `admin-dashboard.html` - halaman pendukung
- `css/` - styling utama, komponen, halaman, responsif
- `js/` - logika app, auth, store, catalog, payment, admin

## Teknologi
- HTML5 Semantic
- CSS3 Variables + Flexbox + Grid
- Vanilla JavaScript ES6
- LocalStorage
- Google Fonts Poppins dan Playfair Display

## Fitur
- Splash screen dan animasi premium
- Sticky navbar dan mobile menu
- Search real-time dan filter produk
- Wishlist dan cart interaktif
- Voucher sederhana dan ringkasan belanja
- Checkout form validasi
- Simulasi pembayaran bank, QRIS, e-wallet, COD
- Success page dan invoice otomatis
- Dashboard admin dummy

## Business Concept
INTAN SHOP memposisikan diri sebagai brand luxury fashion dan jewelry dengan target pasar wanita dan pria usia 20–50 tahun. Fokus bisnis adalah menghadirkan produk premium, desain elegan, dan pengalaman belanja eksklusif.

## Deployment GitHub Pages
1. Push project ke repository GitHub.
2. Buka Settings → Pages.
3. Set source ke `Deploy from a branch`.
4. Pilih branch `main` dan folder root.
5. Tunggu proses deployment selesai.
