# 💎 INTAN SHOP

INTAN SHOP adalah website e-commerce bertema **Luxury Jewelry & Fashion Collection** yang dikembangkan menggunakan **HTML5, CSS3, dan Vanilla JavaScript (ES6)** tanpa menggunakan framework. Website ini dirancang untuk memberikan pengalaman belanja online yang modern, elegan, responsif, dan mudah digunakan.

---

# 📖 Tentang Project

INTAN SHOP merupakan project website e-commerce yang menampilkan berbagai koleksi produk premium seperti:

- Diamond Jewelry
- Gold Jewelry
- Rings
- Necklaces
- Bracelets
- Earrings
- Luxury Watches
- Luxury Bags
- Gift Collection

Website ini memiliki alur transaksi yang lengkap mulai dari login hingga invoice sehingga menyerupai sistem e-commerce sesungguhnya.

# 🛒 Alur Penggunaan

1. Buka halaman Home.
2. Login menggunakan akun Customer atau Admin.
3. Masuk ke halaman Shop.
4. Cari produk menggunakan Search.
5. Filter produk berdasarkan kategori.
6. Lihat Detail Produk.
7. Tambahkan produk ke Cart.
8. Checkout.
9. Pilih metode pembayaran.
10. Pembayaran berhasil.
11. Invoice otomatis dibuat.

# 📦 Instalasi

Clone repository

```bash
git clone https://github.com/USERNAME/intan_shop.git
```

Masuk ke folder project

```bash
cd intan_shop
```

Buka menggunakan Visual Studio Code

```bash
code .
```

Jalankan menggunakan Live Server

atau

```bash
python -m http.server 8000
```

Kemudian buka browser

```
http://localhost:8000
```

# 🚀 Deployment GitHub Pages

1. Push project ke GitHub.
2. Masuk ke repository.
3. Pilih **Settings**.
4. Buka menu **Pages**.
5. Pada **Build and Deployment**, pilih:

```
Deploy from a branch
```

6. Branch

```
main
```

7. Folder

```
/root
```

8. Save.

Website akan otomatis dipublikasikan melalui GitHub Pages.
